# EZTimer

A timer web app for workout plans with granual control on 3 level of steps: phases, circuits and action rounds. Runs purely in browser.

## Key features

- Three level of steps: phases, circuits and action rounds. Each can be customized into any combination;
- Counting down with ticks and beeps;
- Pause and resume capability;
- Auto-focus when switching step / resume.

## How to use

Build the app using npm and deploy the app using any web server (nginx for example) and open the website.
